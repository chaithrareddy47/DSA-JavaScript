## 🧠 Problem-Solving Approach

For every problem:

1. Understand the problem
2. Identify input and output
3. Take a small example
4. Solve it manually
5. Find what repeats or changes
6. Decide what information I need to remember
7. Find the operation that makes progress
8. Decide when to stop
9. Write the approach in words
10. Code it
11. Test with examples
12. Check Time & Space Complexity

### Main Rule

> **Don't memorise the solution. Understand why the solution works.**
